# v0.1.0

## What's new

- Ten interface languages: English, Russian, Kazakh, Portuguese, Spanish, French, German, Chinese, Hindi and Arabic.
- Language selector in Settings with a saved override. Automatic mode follows supported macOS preferred languages and falls back to English.
- Arabic right-to-left interface; telephone numbers and the dial pad retain their normal order.
- Microphone permission preflight in Settings, before calling.
- Multiple saved SIP profiles, one active line and one call.
- Colored availability menu, full-area controls and a compact in-call DTMF panel.
- Hold `0` to enter `+`, native Command-V paste and outside-click panel dismissal.

## Installation

1. Download `SIPDesk-0.1.0-AppleSilicon.dmg` and open it.
2. Drag SipDesk into Applications. Quit a previous instance before replacing it.
3. Open SipDesk, then click the phone icon in the macOS menu bar.
4. In Settings, allow microphone access before calling and configure your SIP profile.

**Requirements:** Apple Silicon Mac, macOS 14 or later. Intel is not supported by this binary.

**Signing:** this build is ad-hoc signed, not Developer ID signed or notarized. Gatekeeper may require Privacy & Security → Open Anyway, where allowed. Do not disable system security. Managed devices may need IT approval.

## Limitations and security

This is an early-stage release, not an emergency-calling solution. Local synthetic SIP tests and audio-configuration tests do not establish physical headset intelligibility or interoperability with every PBX/NAT setup. Verify both audio directions with your provider.

Credentials and history are not included in the image. Existing profiles and UUID-keyed Keychain entries are retained. SIPDesk is GPL-2.0-or-later; source and third-party license notices are included. The release source tag and embedded source archive correspond to this build.
